# RoutineStamp | 습관 기록·성장 Android 앱

일일 습관 실행을 기록하고 연속 달성·캐릭터 성장·수집·위젯으로 반복 행동을 돕는 개인 앱이다.

## 기술과 구성

Java · Android · App Widgets · 로컬 상태 관리

```text
src/: 앱과 위젯 소스
res/: 리소스
RoutineLogicTestMain.java: 날짜·연속 기록 로직 점검
```

## 엔지니어링 관점

달력 경계·윤년·연속 달성 계산, UI 상태와 기록의 연결, 홈 화면 위젯. 배포 이름 v6.7과 BUILD_NOTES 내부 v6.6 표기가 달라 해당 상태를 그대로 기록한다.

## AI를 활용한 개발 방식

이 프로젝트는 AI 개발 도구를 활용한 문제 해결 포트폴리오의 일부다. AI가 코드를 작성했다는 사실보다 문제 정의, 기술 선택, 결과 검토, 실패 원인 분석과 검증 근거를 중심으로 설명한다. 원본 개발 대화 전체는 확인하지 못했으므로 파일별 수작업·AI 작성 비율이나 사용 모델은 추정하지 않는다.

## 시작하기

현재 ZIP은 `AndroidManifest.xml`, `src/`, `res/` 형태의 소스 묶음이다. 바로 실행 가능한 Gradle 빌드라고 소개하지 않는다. 기존 BUILD_NOTES는 이전 버전 이력을 포함한다. 실제 Manifest는 versionName 6.7/versionCode 67이다. 날짜 로직 테스트는 `VALIDATION.md`를 참고한다.

## 실행과 현재 상태

수집된 ZIP은 소스 묶음이며 현대적인 Gradle 앱 프로젝트로의 이관은 완료되지 않았다. 원본 패키지명은 제작 도구를 나타내는 역사적 식별자이며 OpenAI 공식 제품·제휴를 의미하지 않는다. 그림 리소스의 생성·이용 권리는 별도 확인이 필요하다.

이번 공개 준비에서는 원본의 선별 복사와 정적 점검을 수행했다. 지원 도구·장비가 없는 환경에서 실행 성공, 운영 성과, 모델 정확도를 새로 확인한 것으로 주장하지 않는다. 상세 검증 결과는 `VALIDATION.md`에 기록한다.

## 출처·공개 범위

원본 작업 폴더에서 소스를 선별한 공개 준비본이다. 로그·자격증명·로컬 SDK 경로·실제 업무 데이터·실행 바이너리는 제외했다. 기존 저작권 고지와 제3자 라이선스는 유지한다. 원본 파일의 고지와 의존성 이용 조건이 적용되며, 이 저장소의 문서가 새 라이선스를 부여하지 않는다.
